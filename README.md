# Do & Write — 产品需求文档

> UI 参考：`sketches/003-colorful-utility/index.html`（紫蓝渐变卡片风）

---

## 一、项目定位

**一句话：** 手机上的待办 + 灵感收集工具，PWA 免费用。

**使用场景：**
- 刷公众号/抖音/小红书看到好选题 → 一句话记下来，自动识别来源和日期
- 日常待办（交房租、保养车、买礼物）→ 设 DDL，到期提醒
- 写完的选题标「已用」，做完的待办勾掉

---

## 二、技术栈

| 层 | 选型 |
|---|------|
| 前端框架 | React + Vite |
| UI 风格 | Tailwind CSS + 自定义紫蓝渐变 |
| 后端/数据库 | Supabase（免费 500MB） |
| 部署 | Vercel（免费） |
| PWA | vite-plugin-pwa |
| 日期解析 | chrono-node（支持中文自然语言） |

## 三、页面结构

### 3.1 顶部 Hero
- 小字：`✦ 别让想法溜走`
- 大字：`Do & Write`（紫蓝渐变色）

### 3.2 快速输入栏
```
┌──────────────────────────────────┐
│ 🔤 记录，比如「明天写AI工具」   │ 记录 │
└──────────────────────────────────┘
```
输入后自动解析：
- 日期（「明天」→ 2026-07-26）
- DDL（「7天后交」→ 2026-08-02）
- 链接（`mp.weixin.qq.com` → 自动标记「公众号」）

### 3.3 双 Tab 切换

| Tab | 默认 | 什么内容 |
|-----|------|---------|
| 📋 待办 | ✅ 默认显示 | 日常任务，带勾选框 |
| 💡 灵感 | 点击切换 | 选题灵感，带来源标签 |

### 3.4 统计环
显示当前 Tab 的数字统计，例如待办 Tab：
```
  🔴 1 今天到期   🟡 3 待完成   🟢 5 已完成
```

### 3.5 任务列表
按 DDL 紧急程度分三级，自动排序：

| 级别 | 标题 | 颜色 | 规则 |
|------|------|------|------|
| 今天到期 | 📌 今天到期 | 🔴 红 | DDL = 今天 |
| 3 天内 | ⏳ 即将到期 | 🟡 黄 | 今天 < DDL ≤ 3 天后 |
| 以后 | 🗓 以后 / 有空再做 | 🔵 蓝 | DDL > 3 天或无期限 |

## 四、卡片样式

### 4.1 待办卡片
```
┌──────────────────────────────────────┐
│ 🔧  ○ 给车做保养，约了下午3点         │
│      🔴 今天截止                      │
└──────────────────────────────────────┘
```
- 左侧：emoji 图标（圆形浅蓝底）
- 中间：勾选框 + 文字
- 底部：时间 badge
- 勾选后：文字划线 + 整卡降透明度 + 统计环更新

### 4.2 灵感卡片
```
┌──────────────────────────────────────┐
│ 📱  AI Agent 给普通人带来的5个改变     │
│    公众号  数字生命卡兹克  🔴 今天截止 │
└──────────────────────────────────────┘
```
- 左侧：来源图标（绿=公众号，红=抖音，橙=小红书，蓝=网页）
- 底部：来源标签 + 来源名 + DDL badge
- 已用：整卡降透明度 + 标题划线

## 五、链接自动识别

输入检测到 URL 时：

| 域名匹配 | 标记来源 | 图标色 |
|----------|---------|--------|
| `mp.weixin.qq.com` | 公众号 | 🟢 绿 |
| `douyin.com` / `v.douyin.com` | 抖音 | 🔴 红 |
| `xiaohongshu.com` / `xhslink.com` | 小红书 | 🟠 橙 |
| 其他 | 网页 | 🔵 蓝 |

## 六、自然语言日期解析

使用 `chrono-node`，支持中文：

| 输入 | 解析结果 |
|------|---------|
| 「明天」 | 当前日期 +1 |
| 「后天」 | 当前日期 +2 |
| 「7天后」「一周后」 | 当前日期 +7 |
| 「下周五」 | 推算到下周五 |
| 「8月15日」 | 直接取 8/15 |
| 「下个月5号」 | 下月 5 日 |
| 无日期 | 归入「未设期限」 |

如果有「交」字（如「7天后交」），该日期 = DDL。

## 七、Supabase 数据结构

### 表 `tasks`
```sql
id          uuid PK
user_id     uuid FK → auth.users
type        text        -- 'todo' | 'inspo'
content     text        -- 任务内容
source      text        -- 'wechat'|'douyin'|'xhs'|'web'|null
source_url  text        -- 原始链接（可为空）
source_name text        -- 来源名（如「数字生命卡兹克」）
due_date    date        -- DDL（可为空）
created_at  timestamptz
done_at     timestamptz -- 完成时间（null=未完成）
```

### 认证
- Supabase Auth，邮箱注册即可
- 首次打开 → 登录页 → 进入主界面

## 八、DDL 提醒

- 每次打开 App → 检查今天到期的任务 → 统计环数字更新
- 红色 = 今天到期，黄色 = 3 天内，蓝色 = 以后
- PWA 暂不做推送通知（需要付费），视觉提醒足够

---

## 九、悬浮按钮

右下角紫色渐变 `+` 按钮：
- 待办 Tab → 打开「添加待办」弹窗
- 灵感 Tab → 打开「添加灵感」弹窗
- 弹窗内容：文本框 + 日期选择器（可选）+ 快速提交
